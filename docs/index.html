What it does

TimeCapsule records which files you created, edited or deleted in folders you choose, then answers questions like what you worked on on a given day, when you last touched a file, or what else you worked on around the time of a presentation. Nothing is recorded until you add a folder, and file contents are never stored.

Install

Windows

Install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then in PowerShell:
py -m pip install git+https://github.com/mohamed-elshamy-ai/timecapsule
timecapsule add $HOME\Projects
timecapsule watch
Untested. Should work (Python standard library only). Only tested on Linux.

macOS

Python 3.9+ (brew install python or python.org), then in Terminal:
python3 -m pip install git+https://github.com/mohamed-elshamy-ai/timecapsule
timecapsule add ~/Projects
timecapsule watch
Untested. Should work. Only tested on Linux.

Linux

Python 3.9+ is usually installed. In a terminal:
python3 -m pip install --user git+https://github.com/mohamed-elshamy-ai/timecapsule
timecapsule add ~/Projects
timecapsule watch
Tested. Tested on Linux (Python 3.10).

Android

Not available. Not available. Android apps cannot watch other apps' folders this way, and a website cannot read your folders, so there is no browser demo either.

How it worksإزاي بيشتغل

  1. You pick the folders. The first scan is only a snapshot.
  2. Every few seconds the folders are scanned and each new, changed or removed file becomes an event.
  3. Events are stored in a local SQLite file.
  4. Ask by day, by file name, or with 'around' to see what else you touched in the same hours.
  5. Pause, exclude or delete history at any time.

Honest limits

  • It sees file changes only. It does not know when you open a file, visit a website or use an app.
  • Search is by file name and time. No search inside contents and no meaning-based search yet.
  • Polling, not OS file events, so large folders cost some CPU.
  • No browser extension or window app yet.
